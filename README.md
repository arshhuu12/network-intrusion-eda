\# Comparative EDA and Visual Analytics of Network Intrusion Detection Datasets



\## Project Overview



This project investigates the data-quality characteristics,

class distributions, feature relationships, and train-test

differences of two network intrusion detection datasets:



\- NSL-KDD

\- UNSW-NB15



The project is motivated by an IEEE ACIT 2023 research paper

comparing intrusion detection techniques across benchmark datasets.



\## Research Objectives



1\. Understand dataset structures and feature characteristics.

2\. Assess data quality.

3\. Investigate class imbalance and feature distributions.

4\. Compare dataset characteristics and train-test differences.

5\. Communicate findings through statistical visualizations.
